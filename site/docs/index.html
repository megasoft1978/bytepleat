Bytepleat · version 0.5.1

Compress files. Pack folders.

Use one command family for file streams and folder archives: compress, pack, inspect, test, and restore supported data in established formats. Successful lossless file workflows restore the same input bytes.

Install

Version 0.5.1 is available for the tested targets. Check the GitHub releases list for an available package and its SHA-256 sidecar. Follow the platform-specific verification and extraction steps in RELEASE.md. A checksum detects accidental corruption when compared with the sidecar; it is not a signature.

Rust users with a C compiler toolchain can install the tagged source with:

cargo install --locked --git https://github.com/megasoft1978/bytepleat --tag v0.5.1

See the home page for the download button. Packages are unsigned and macOS builds are not notarized.

Windows packages require the x64 Microsoft Visual C++ v14 runtime, which is not bundled.

Compress one file

bytepleat compress ./notes.txt --format gzip
bytepleat decompress ./notes.txt.gz -o ./notes-restored.txt

zstd is the default; gzip and LZ4 are also supported. Decompression detects the stream format and writes a new output file, leaving the input archive intact. Already-compressed or encrypted data may not shrink.

Package a directory

bytepleat pack ./project --format zstd -o project.tar.zst
bytepleat info project.tar.zst
bytepleat test project.tar.zst
bytepleat unpack project.tar.zst --output ./restored-project

ZIP and 7z also package supported subsets of directory archives. Directory archives store file contents and relative paths; ownership, permissions, and other filesystem metadata are not all preserved. Extract to a new destination directory.

Formats at a glance

  • Zstandard, gzip, LZ4 frames: single-file streams and compressed tar archives.
  • ZIP: classic Stored/Deflate subset. 7z: bounded LZMA2 subset. Both can be packaged, inspected, tested, and unpacked within those limits.
  • RAR: metadata recognition only; Bytepleat does not decode it.
  • Pco: typed numeric data from raw little-endian values. Supply an explicit --type; this does not parse CSV text.

For fuller read/write boundaries, see the format notes.

Choose a codec setting

For Zstandard, --preset fast, balanced (default), and compact select levels 1, 3, and 9. For gzip, they select levels 1, 6, and 9. They are codec settings, not Bytepleat speed or size guarantees; results depend on the input. --level overrides the preset where supported. LZ4 has one level. Pco requires an explicit numeric --type.

Limits and careful use

test reads the supported payload fully and checks format integrity and available checksums without extracting files. info reports bounded metadata and does not decode the full payload. Neither proves source identity or content safety. Path checks and configured limits address specific extraction risks, but they are not a general security guarantee or total process-memory cap. Extraction needs a new destination; multi-file publication is not atomic. Folder archives restore file contents and relative paths, not permissions, ownership, links, extended attributes, or portable timestamps. See security and limits.
