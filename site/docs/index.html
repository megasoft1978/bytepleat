Getting started

Arqlet is a Rust command-line tool for lossless compression of individual files and directory archives using established formats. This guide covers the first steps and the practical limits to keep in mind.

Install

The first public release is pending, so release assets are not yet available. When published, use the GitHub releases page to select an available build and compare its SHA-256 checksum with the value published for that asset. On macOS or Linux, calculate a local checksum with:

shasum -a 256 ./arqlet-release.tar.gz

On Windows PowerShell, use Get-FileHash .\arqlet-release.zip -Algorithm SHA256. Planned architecture targets are listed on the home page; they are not confirmation that a build or native test exists.

With Rust installed, the planned source install is:

cargo install --locked --git https://github.com/megasoft1978/arqlet --tag v0.5.0

This requires the v0.5.0 tag to be published. Check the current release state before using it.

Compress one file

arqlet compress ./notes.txt --format gzip
arqlet decompress ./notes.txt.gz -o ./notes-restored.txt

Formats include zstd (the default), gzip, and LZ4. Decompression detects the stream format. The output is byte-for-byte the original input when decoding succeeds. Already compressed or encrypted data often does not get smaller.

Package a directory

arqlet pack ./project --format zstd -o project.tar.zst
arqlet info project.tar.zst
arqlet test project.tar.zst
arqlet unpack project.tar.zst --output ./restored-project

Directory archives carry file contents and relative paths. The archive format does not promise to preserve every filesystem attribute, such as ownership or permissions. Extract into a new, controlled destination; inspect unfamiliar archives first.

Formats at a glance

  • zstd, gzip, LZ4: single-file compression streams; also used to carry Arqlet's tar directory archives.
  • ZIP and 7z: archive creation, inspection, testing, and extraction workflows.
  • pco: typed numeric streams; choose an explicit numeric type where required.

Each format has its own compatibility and integrity properties. A successful test cannot prove the origin or safety of an archive.

Safe, careful use

  • Keep a separate backup of important data before replacing or deleting originals.
  • Inspect archive contents and only unpack files from sources you trust.
  • Use a new output directory you control. Extraction path checks reduce traversal risks, but do not make untrusted content harmless.
  • Compare checksums when you need to detect accidental changes. A checksum alone does not identify who created the file.
  • Use resource limits when processing files you did not create.

Help improve Arqlet

Report reproducible behavior, clarify what format and command you used, and include safe sample inputs where possible. Read the repository's contribution and issue guidance.
