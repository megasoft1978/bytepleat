Arqlet · version 0.5.0

Getting started

Arqlet compresses individual files and packages directories with established formats. Successful decompression restores the original input bytes exactly.

Install

The first public release is pending. Check the GitHub releases list for an available package and its SHA-256 value. Compare locally with shasum -a 256 ./arqlet-release.tar.gz on macOS/Linux or Get-FileHash .\arqlet-release.zip -Algorithm SHA256 in PowerShell. Only run a build after the checksum matches.

When the v0.5.0 source tag is published, Rust users can install with:

cargo install --locked --git https://github.com/megasoft1978/arqlet --tag v0.5.0

See the platform list for target status; a listed target does not by itself mean a package is available.

Compress one file

arqlet compress ./notes.txt --format gzip
arqlet decompress ./notes.txt.gz -o ./notes-restored.txt

zstd is the default; gzip and LZ4 are also supported. Decompression detects the stream format and writes a new output file, leaving the input archive intact. Already-compressed or encrypted data may not shrink.

Package a directory

arqlet pack ./project --format zstd -o project.tar.zst
arqlet info project.tar.zst
arqlet test project.tar.zst
arqlet unpack project.tar.zst --output ./restored-project

ZIP and 7z also package supported subsets of directory archives. Directory archives store file contents and relative paths; ownership, permissions, and other filesystem metadata are not all preserved. Extract to a new destination directory.

Formats at a glance

  • zstd, gzip, LZ4: single-file streams and compressed tar directory archives.
  • ZIP and 7z: package, inspect, test, and unpack supported archive subsets.
  • pco: typed numeric data from raw little-endian values. Supply an explicit --type; this does not parse CSV text.

Limits and safe use

Inspect unfamiliar archives and use resource limits for untrusted inputs. Path checks reduce extraction risks but cannot make archive contents safe. Checksums detect changes, not authorship. Keep backups of important files. Output paths must be new.
