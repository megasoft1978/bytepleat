Files in.

Arqlet is a Rust tool for compressing individual files and packaging directories with established formats. It is built around a simple promise: restore the original file bytes exactly.

Choose the right shape

One file, or a whole folder.

Arqlet uses familiar, documented formats instead of a new proprietary compression stream. Pick a format that fits the data and the tools around it.

A short tour

Pack. Check. Unpack.

These examples show the shape of the workflow: make an archive, inspect it, then restore it to a chosen directory.

Package a directory
arqlet pack ./project --format zstd -o project.tar.zst

Creates a standard compressed tar archive from the folder.

Check the archive
arqlet test project.tar.zst

Tests the stream or archive for decode and integrity errors supported by its format.

Restore a directory
arqlet unpack project.tar.zst --output ./restored-project

Writes the archived entries into a new destination directory.

Compress a single file
arqlet compress ./notes.txt --format gzip

Creates a gzip stream beside the input; decompression detects the stream format.

the same bytes outinput = restored outputby design

Examples assume Arqlet is installed and that output paths do not already exist. See the guide for options and safety details.

Careful by default

Archives deserve a second look.

Compression is one part of file handling. Arqlet also makes archive extraction an explicit step with limits and path checks.

Review before restoring

Inspect archive contents and only unpack files from sources you trust. Set an output directory you control, and keep a separate backup for important data.

Integrity has limits

Checksums can detect changes where a format provides them; they do not prove who created a file or guarantee that an archive is safe. A successful test is not a security certificate.

Exact means bytes

Arqlet's lossless file workflows preserve the input bytes when decompressed. Metadata such as paths and filesystem attributes is a separate concern.

Good to know

Questions, plainly answered.

Does Arqlet invent its own compression format?

No. Its file and archive workflows use established formats such as zstd, gzip, LZ4, ZIP, and 7z. Pco is available for typed numeric data.

Will every file get smaller?

No. Compressed, encrypted, or already optimized files may not shrink and can grow slightly. Choose a format based on compatibility and the kind of data you have.

Is the 0.5.0 download available now?

The initial public release is pending. The download link points to GitHub's latest release page, which will show assets and checksums when the coordinator publishes them.
