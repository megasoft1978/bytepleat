Good to know

Questions, plainly answered.

Is the desktop app ready to download?

Not yet. It is in development. Follow the draft development PR for progress; no desktop installer is offered here.

Can I open RAR archives?

RAR files are not supported for extraction. Use a compatible archive tool to extract them first.

Can I open password-protected or ZIP64 archives?

Those archive features are not supported by the current desktop app. See the format guide for supported subsets.

Does opening an archive check its contents?

Opening shows a bounded entry list. Use extraction to decode and check the supported archive contents before files are published. Selected extraction decodes the whole archive first.

Does Bytepleat change my original files?

Creating an archive leaves the selected originals in place. Extraction writes files to the destination you choose. Review the destination and existing-file behavior before proceeding.

Where are the command-line downloads?

Bytepleat CLI 0.5.1 packages for macOS Apple silicon, Linux x86-64, and Windows x86-64 are available above with checksums and install commands.
