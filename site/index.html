Download, verify and run

Three things, done carefully

Create an archive
Choose files or a folder, pick ZIP, 7z or compressed tar, and say where it goes. Bytepleat writes to a temporary file and only gives it the final name when it is complete.
Extract into a new folder
Everything lands in a fresh folder, never on top of existing files. Unsafe paths, links and special files are refused before anything is written.
Look inside first
Inspect lists what an archive holds without extracting anything. Test decodes every byte to check that it is intact.

What Bytepleat will not do

Overwrite your files by surprise
An existing output stops the job unless you pass --force. Extraction always goes into a new folder. Your input files are never moved or removed.
Send anything anywhere
No accounts and no uploads. It reads and writes files on your device and works offline.
Leave a mess when you cancel
Named outputs are written to a temporary file first, so stopping a job leaves your existing files as they were.
Invent a format
Everything it writes is standard ZIP, 7z, tar, Zstandard, gzip or LZ4, and opens in the tools you already have.
Make speed or size claims
Results depend on your files. The benchmark notes publish the method, so you can rerun them and judge.

Install

Version 0.5.2 of the command-line tool, as one archive per system. Packages are not signed yet, so check the SHA-256 checksum before you run it. A checksum catches a damaged download; it does not prove who built the file.

macOS

For Macs with Apple silicon. On an Intel Mac, install from source.

Download for macOS SHA-256 checksum file

  1. Download

    Get the archive and its checksum file.

    Terminal
    curl -fL --remote-name-all \
https://github.com/megasoft1978/bytepleat/releases/download/v0.5.2/bytepleat-0.5.2-aarch64-apple-darwin.tar.gz \
https://github.com/megasoft1978/bytepleat/releases/download/v0.5.2/bytepleat-0.5.2-aarch64-apple-darwin.tar.gz.sha256

  2. Check the checksum

    It should print OK. Anything else means the download is damaged.

    Terminal
    shasum -a 256 -c bytepleat-0.5.2-aarch64-apple-darwin.tar.gz.sha256

  3. Open it

    Extract the folder and run the tool from it. Add that folder to your PATH to run bytepleat from anywhere.

    Terminal
    tar -xzf bytepleat-0.5.2-aarch64-apple-darwin.tar.gz && ./bytepleat-0.5.2-aarch64-apple-darwin/bytepleat --help

Packages are not signed yet and the macOS build is not notarised. If macOS blocks the first run, here is how to open it anyway.

Quick start

Zstandard is the default. Use --format for gzip, LZ4, ZIP or 7z. The command-line guide covers the rest.

Terminal
# compress one file, then restore it
bytepleat compress report.pdf
bytepleat decompress report.pdf.zst -o report-restored.pdf

# pack a folder, then unpack it into a new folder
bytepleat pack project -o project.tar.zst
bytepleat unpack project.tar.zst -o project-restored

# look inside without extracting, then fully decode and check
bytepleat info project.tar.zst
bytepleat test project.tar.zst

Formats

Support means a defined subset, not every file that carries the extension.

ZIPYesYesClassic Stored and Deflate only. Up to 65,534 entries.
7zYesYesWrites LZMA2. Reads a bounded set of methods, unencrypted and single-volume. Up to 100,000 entries.
tar + ZstandardYesYesRegular files and folders only. Links and special files are refused.
tar + gzipYesYesRegular files and folders only. Links and special files are refused.
tar + LZ4YesYesRegular files and folders only. Links and special files are refused.
Zstandard, gzip, LZ4 single file, command line onlyYesYesOnly Zstandard uses several threads. LZ4 files made of joined frames are refused.
RARNoRecognised onlyinfo can tell you it is RAR. Nothing is extracted.

Not supported: passwords and encryption, ZIP64, split archives, RAR extraction. Folder archives keep file contents and relative paths, not permissions, ownership, links or timestamps. Exact limits

When to use something else

Bytepleat is small and strict on purpose. Mature tools do more.

Creates archivesYes: ZIP, 7z, and tar with Zstandard, gzip or LZ4
Opens RARNo. It recognises RAR but does not extract it.
Passwords and encryptionNo
Full filesystem backupNo. Permissions, ownership, links, extended attributes and timestamps are not restored.

If a “No” above matters to you, use a mature archiver such as 7-Zip, Keka, The Unarchiver, or tar with zstd. Check each project's own site for what it supports today. We do not summarise other tools here, because their features change and we have not verified them for this page.

Questions

Why is it called Bytepleat?

A pleat is a fold that makes something wide compact and lets it open flat again. That is the job.

Is it faster or smaller than other archivers?

It uses the same standard codecs, so results depend on your files and settings. We make no general speed or size claim. The benchmark notes show the method and results so you can judge.

Does it upload my files?

No. Bytepleat works on files on your device, needs no account, and runs offline.

Why does macOS block the first run?

The packages are not signed and the macOS build is not notarised yet. Check the SHA-256 checksum first. Then open System Settings, go to Privacy & Security, and choose Open Anyway for bytepleat. Files downloaded with curl are usually not blocked.

Can it open RAR or password-protected ZIP files?

Bytepleat recognises RAR files but does not extract them. Password-protected ZIP files and encryption are not supported.

What happens if I cancel?

The job stops. Named outputs are written to a temporary file first, so an unfinished archive never takes the final name, and your originals are untouched. Output sent to standard output is a stream and can be partial.

Is it safe to extract archives from strangers?

Bytepleat refuses unsafe paths and links and applies size and entry limits, but that is not a security guarantee, and test does not scan for malware. See the security and limits notes.

Is the desktop app ready for daily use?

Not yet. It is an alpha you build from source. The command-line tool is further along.
