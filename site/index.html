Free and open source

Pack and unpack archives from the command line.

Bytepleat compresses files, packs folders, and unpacks, inspects and tests archives in ZIP, 7z, tar with Zstandard, gzip or LZ4. It leaves your originals alone and refuses to overwrite existing files.

Download the CLI (v0.5.1) Desktop app (alpha, build from source)
Install from source (Rust 1.93+)
cargo install --locked --git https://github.com/megasoft1978/bytepleat --tag v0.5.1

Packages are unsigned. A checksum catches accidental corruption; it is not a signature. Windows needs the x64 Visual C++ runtime.

What you can count on

Many formats

ZIP, 7z, and tar archives compressed with Zstandard, gzip or LZ4, plus single-file compression. One tool instead of several.

Never overwrites your files

Originals are never removed. If the output file already exists, Bytepleat stops unless you pass --force, and unpacking needs a new folder.

Cancel any time

Output is written to a temporary file and only put in place when the job succeeds. Stop a job with Ctrl-C and your existing files are unchanged.

Quick start

Five commands cover most of what you will do. Run bytepleat --help for the rest.

Terminal
# compress one file (Zstandard by default)
bytepleat compress report.pdf

# pack a folder into an archive
bytepleat pack project -o project.tar.zst

# list what is inside, without extracting
bytepleat info project.tar.zst

# check the archive reads back cleanly
bytepleat test project.tar.zst

# unpack into a new folder
bytepleat unpack project.tar.zst -o project-restored

Use --format zip or --format 7z with pack to make those archives. See the command-line guide.

Supported formats

Support means a defined subset, not every file that carries the extension.

FormatCreateOpen and testLimits
ZIPYesYesClassic Stored and Deflate only. No ZIP64, no encryption, no split archives.
7zYesYesA subset: LZMA2 for writing; common methods for reading. No encryption, no split archives.
tar + Zstandard, gzip, LZ4YesYesRegular files and folders only. Links and special files are rejected.
Single files (.zst, .gz, .lz4)YesYesLZ4 files made of several joined frames are rejected.
RARNoNoIdentified by info only. Not extracted.

Folder archives keep file contents and relative paths, not permissions, ownership or links. Details: format notes.

Why Bytepleat, and when to use something else

Pick Bytepleat when

  • You want one consistent set of commands across ZIP, 7z and tar-based formats.
  • You want safe defaults: no silent overwrites, and a test command to check an archive.
  • You are scripting on macOS, Linux or Windows and want the same behavior everywhere.

Pick something else when

  • zip / unzip: you need ZIP64, encryption, or to edit an existing archive in place.
  • 7-Zip: you need the full 7z feature set, encrypted archives, or RAR extraction.
  • tar with zstd: it is already installed and your needs are met; you need file attributes, links or sparse files preserved.

Desktop app: alpha

A desktop app for browsing and extracting archives is in early alpha. There is no installer yet; you can build it from source, and it has not had broad testing. Progress and test notes are in the desktop validation notes. The command-line tool above is the supported way to use Bytepleat today.

Questions

Does Bytepleat change my original files?

No. Compressing or packing leaves the input in place. Output files are written to a temporary file first and moved into place when the job finishes. An existing output is an error unless you pass --force.

Can it open RAR, password-protected or ZIP64 archives?

No. RAR is only identified, not extracted. Encrypted archives and ZIP64 are not supported. Use a tool such as 7-Zip for those.

Does info check that an archive is valid?

It reads a limited amount of metadata and does not decode everything. Use test to read the whole archive and check it.

Is a checksum the same as a signature?

No. Comparing a download with its SHA-256 catches accidental corruption. Packages are unsigned, and macOS builds are not notarized, so macOS may ask you to confirm the first run.

Is it safe to unpack archives from strangers?

Bytepleat rejects unsafe paths and applies size limits, but that is not a security guarantee. Treat untrusted archives with care. See the limits notes.

Is the desktop app ready?

Not yet. It is an alpha you can build from source. See the status above.
