Choose the right shape

One file, or a whole folder.

Start with Zstandard for everyday files, choose gzip for broad tool compatibility, or use the throughput-oriented LZ4 codec. Package folders as compressed tar, ZIP, or 7z within the documented subsets.

FormatForBytepleat workflow

LZ4Throughput-oriented frame streamsCompress · decompress · pack
ZIP / 7zSupported directory archive subsetsPack · inspect · test · unpack
pcoTyped raw little-endian valuesNumeric streams · explicit --type

Pco reads typed raw values; it does not parse CSV. For Zstandard and gzip, choose --preset fast, balanced (default), or compact; to select codec levels. Time and size depend on your files. LZ4 has one level. See the guide for details.

A short tour

Pack. Check. Unpack.

These examples show the shape of the workflow: make an archive, inspect it, then restore it to a chosen directory.

Package a directory
bytepleat pack ./project --format zstd -o project.tar.zst

Creates a standard compressed tar archive from the folder.

Check the archive
bytepleat test project.tar.zst

Tests the stream or archive for decode and integrity errors supported by its format.

Restore a directory
bytepleat unpack project.tar.zst --output ./restored-project

Writes the archived entries into a new destination directory.

Compress a single file
bytepleat compress ./notes.txt --format gzip

Creates a gzip stream beside the input; decompression detects the stream format.

the same bytes outinput = restored outputby design

Examples assume Bytepleat is installed and that output paths do not already exist. See the guide for options and safety details.

Know what each command checks

Inspect. Test. Then unpack.

info reads bounded metadata. test decodes supported content and checks format integrity and available checksums without extracting files. Neither can establish who sent an archive or whether its contents are safe.

Review before restoring

Inspect archive contents and unpack only trusted files into a new directory you control.

Integrity has limits

Checksums detect changes; they do not prove who created a file or that it is safe.

Exact means bytes

Lossless file workflows restore input bytes. Paths and filesystem attributes are separate metadata.

Good to know

Questions, plainly answered.

Does Bytepleat invent its own compression format?

No. Its file and archive workflows use established formats such as zstd, gzip, LZ4, ZIP, and 7z. Pco is available for typed numeric data.

Will every file get smaller?

No. Compressed, encrypted, or already optimized files may not shrink and can grow slightly. Choose a format based on compatibility and the kind of data you have.

How do I choose a compression setting?

For Zstandard or gzip, fast, balanced, and compact choose codec levels. Time and size depend on your files. Compressed, encrypted, or already optimized files may not shrink and can grow slightly.
