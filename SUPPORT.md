# Support

Use [GitHub Issues](https://github.com/megasoft1978/bytepleat/issues) for usage questions, reproducible bugs, and format compatibility reports. Search existing issues first. Include the Bytepleat version, operating system and architecture, command, and relevant error text. Remove private paths and data before posting.

For suspected security vulnerabilities, use the private process in [SECURITY.md](SECURITY.md), not a public issue. Bytepleat is a community-supported open-source project; no paid support or response-time commitment is offered.
