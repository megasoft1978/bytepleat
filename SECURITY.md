# Security policy

Bytepleat handles untrusted compressed streams and archive metadata. Please report suspected vulnerabilities privately so maintainers can assess and coordinate a fix before details are public.

Use the repository's **Security → Advisories → Report a vulnerability** flow on GitHub: https://github.com/megasoft1978/bytepleat/security/advisories/new. If private reporting is not enabled or that page is unavailable, contact the repository maintainers through GitHub and ask for a private vulnerability-reporting route. Do not post exploit details in a public issue while seeking that route.

There is no published response-time SLA. Please include the affected version, platform, impact, reproduction steps, and any safe proof-of-concept needed to understand the issue. Avoid including real user data or destructive payloads.

Bytepleat's safety checks and configured limits reduce accepted input scope but are not a security certification or proof of absence of vulnerabilities. See [security and limits](docs/security-limits.md).
